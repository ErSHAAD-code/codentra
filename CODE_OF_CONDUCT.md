# Code of Conduct

Codentra follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful, be constructive, and assume good faith. Harassment, discrimination, or abusive behavior toward any contributor will not be tolerated. Reports can be raised via a GitHub issue marked `conduct` or by contacting the maintainers directly.
